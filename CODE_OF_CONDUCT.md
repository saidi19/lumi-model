# Community conduct

Lumi welcomes constructive technical discussion across backgrounds and experience
levels. Be respectful, explain disagreements with evidence, and credit others'
work. Critique code and claims rather than attacking people.

Harassment, discriminatory abuse, threats, doxxing, unsolicited sexual content,
spam and deliberate disclosure of private information are not acceptable in
project issues, pull requests or other project-maintained spaces.

The repository maintainer may edit or remove harmful content, lock discussion,
or restrict participation proportionately. Where safe, explain the reason and
allow clarification. These guidelines do not promise around-the-clock moderation
or a response deadline.

For a sensitive report, ask the maintainer for a private reporting channel
without posting the details publicly. A dedicated private conduct-reporting
address has not been established. Security issues follow SECURITY.md. Do not
publish a victim's personal information while requesting help.
