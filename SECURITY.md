# Security reporting

This research project does not currently promise a supported production release,
a response SLA or a vulnerability-free implementation.

Do not post credentials, private model/data records, infrastructure access details
or exploitable sensitive disclosures in public issues, logs or pull requests.
If GitHub displays **Security → Report a vulnerability** for this repository,
use that private channel. On 2026-10-15 the repository API reported that private
vulnerability reporting was disabled. If unavailable, ask the maintainer for a private reporting channel
without including the vulnerability details. No private contact address is
invented or promised here.

A useful private report includes affected commit/version, impact, minimal
synthetic reproduction and suggested mitigation. Do not access others' data,
run cloud workloads, or test against live services without permission.

If a credential has been exposed, revoke or rotate it through its provider;
deleting a current file alone does not remove it from history. Coordinate any
history rewrite with the maintainer rather than doing it as routine cleanup.
